# 67 CAD v1.1-beta — Список изменений

### Новые компоненты
- **TP4056** — модуль зарядки Li-ion.
- **Генератор дуги**
- **Батарейный отсек** — с редактируемым номиналом (одинарный клик).
- **Тумблер** — с двумя редактируемыми положениями (формат `1,0`).
- **Штепсельная вилка** — 3 контакта, адаптируется под тему.

### Новые возможности
- **Фильтр компонентов** — живой поиск по библиотеке в боковой панели.
- **Привязка к сетке** — кнопка «Привязка к сетке» (шаг 20 px при перемещении и ресайзе записок).
- **Выделение рамкой** — протяжка левой кнопкой по пустому месту.
- **Подсветка целевого пина** — при трассировке пин под курсором обводится зелёным.
- **Автоперенос строк в записках** — текст больше не вылезает за границы.
- **Отмена правок записки** — `Escape` возвращает текст к состоянию до редактирования.
- **Улучшенная валидация импорта** — битые файлы отклоняются с понятным сообщением, старые файлы (v1.0) автоматически мигрируют.

### Исправлено
- Смещение координат мыши при свёрнутой панели.
- Лишние шаги в истории при простом клике по компоненту.
- Коллизия ID при импорте.
- Падение редактора на повреждённых данных.
- Постоянный таймер мигания курсора (теперь только при редактировании).

### UI
- Переработана боковая панель.
- Версия в шапке обновлена до **v1.1**.

## Технические изменения (кратко)

- Глобальное состояние вынесено в объект `State` (камера / взаимодействие / UI); добавлены константы `GRID`, `MAX_COORD`, `WIRE_COLORS`.
- Отрисовка переведена на `requestAnimationFrame`-батчинг (`scheduleDraw`); рендереры компонентов стали полиморфными (`COMPONENT_RENDERERS`) с единой точкой `renderComponent` и `wrapText` для записок.
- Добавлены `validateSchema` и `migrateComponentType` для безопасного импорта; `getPinPos`/`drawWirePath` валидируют координаты и не роняют рендер.
- Полифилл `roundRect` для старых браузеров; `getMousePos` исправлен на `getBoundingClientRect`.
- История пишется только при реальном сдвиге (`pendingHistory`, порог 2 px); `nextId` пересчитывается по максимальному ID.
- CSS: `--sidebar-width` вместо магического `260`, стили для `.filter-input`.
